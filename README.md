**ESP32-S3 Custom Development Board**

A custom-designed ESP32-S3 development board focused on embedded hardware design, schematic development, and PCB engineering.
The project follows a structured hardware development approach, covering:

1)Hardware requirements and specifications
2)System block diagram
3)Component selection and datasheet analysis
4)Power budget and power management
5)Schematic capture using KiCad
6)PCB layout and routing
7)Design verification and documentation

Objective: To develop a practical ESP32-S3 hardware platform while gaining hands-on experience in professional PCB design practices and embedded hardware development

_EDA Tool: Orcad Capture CIS and Allgero_

_Application Areas: Embedded Systems, IoT, and Hardware Prototyping._
